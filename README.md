# 北九州観光事業MVP
## 事業内容
地域の紹介はしたいけどガイドする体力がないお年寄りが電話ツアーを通してガイドを行う。
旅行者が一時間千円払い、手数料を得る。
紹介の例:危険な山登りのガイド、釣りポイント

史跡は潰される。勝手に開発用地になり、解体される。
史跡を守りたい。そのために、訪れるひとを増やす。知ってもらう。
史跡を説明してくれるひとをつなげる。
史跡だけでなく、観光全般を扱う。
会社の歴史もありそうだけど、今はやらない。

## 作る内容
タイムスリップ旅行マップ。
その地域に絞り、地図を用意する。まずは門司区。
史跡をピン留め、場所をマッピング。
年表をスライダーで移動しその年代のピンを見せる。
年代に合わせ、背景のフレーバー画像を見せる。江戸時代なら浮世絵の雲をマップ外に表示したり、維新は有名人、大正以降は機関車とその煙、戦争期は煙と戦艦、高度経済成長期は関門橋と工場の煙突。
大まかな位置でも、範囲でビジュアル化すれば用意できる。
地図は門司区の外も、範囲外だけど地区名と海岸線くらいは描写する。
レベルを作る。説明できる深度に合わせて、深い説明ができて、ガイドにも繋げられるものは大きく、軽い説明と画像だけなら小さく表示する。大きいスポットはズームアウト時に表示し、小さいスポットはズーム時に表示。
AR体験。
史跡の連なりも、テーマで見せる。

## デモンストレーションのための割り切り
説明に使うものだけに絞り、以下の機能を先行して実装する。
360度の横長の生成画像を用意して、擬似的なAR体験。
地図を3D化し、地域の歴史をビジュアル化アニメーション化して説明(壇ノ浦が有力)
「ガイドとつながる」ボタンを用意して、擬似的な決済シーケンス、そして実際にガイドに電話を繋げる(イニシャル実装時はダミー番号)
