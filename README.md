# 北九州観光事業MVP
## 事業内容
地域の紹介はしたいけどガイドする体力がないお年寄りが電話ツアーを通してガイドを行う。
旅行者が一時間千円払い、手数料を得る。
そうしたコンセプト、アイデアソンの架空の事業のためのMVP。

史跡は潰される。勝手に開発用地になり、解体される。
史跡を守りたい。そのために、訪れるひとを増やす。知ってもらう。
史跡を説明してくれるひとをつなげる。
史跡だけでなく、観光全般を扱う(がMVPは歴史がからむものしか扱わない)
会社の歴史もありそうだけど、今はやらない。

## 作る内容
タイムスリップ旅行マップ。
その地域に絞り、地図を用意する。まずは門司区。
史跡をピン留め、場所をマッピング。
年表をスライダーで移動しその年代のピンを見せる。
年代に合わせ、背景のフレーバー画像を見せる。江戸時代なら浮世絵の雲をマップ外に表示したり、維新は有名人、大正以降は機関車とその煙、戦争期は煙と戦艦、高度経済成長期は関門橋と工場の煙突。
大まかな位置でも、範囲でビジュアル化すれば用意できる。
地図は門司区の外も、範囲外だけど地区名と海岸線くらいは描写する。
レベルを作る。説明できる深度に合わせて、深い説明ができて、ガイドにも繋げられるものは大きく、軽い説明と画像だけなら小さく表示する。大きいスポットはズームアウト時に表示し、小さいスポットはズーム時に表示。
AR体験。
史跡の連なりも、テーマで見せる。

## デモンストレーションのための割り切り
説明に使うものだけに絞り、以下の機能を先行して実装する。
360度の横長の生成画像を用意して、擬似的なAR体験。
地図を3D化し、地域の歴史をビジュアル化アニメーション化して説明(壇ノ浦が有力)
「ガイドとつながる」ボタンを用意して、擬似的な決済シーケンス、そして実際にガイドに電話を繋げる(イニシャル実装時はダミー番号)

## イメージ
### ノリ
事業向けにも使えることを想定。
そのため、API依存はせず、オフラインでも稼働可能。
### 初期画面
コンセプトを理解させるため、アクセス直後、年表のスライダーを最初から最後まで1秒かけてざっと動かす。もちろん年代に合わせ背景の遷移も行う。
そして最後まで行くと、自然に現代になっていて、それが初期画面となる。現代から遡る形でどんどん進んでいく感じで体験することになる。
### 基本画面
上にタイトル。「門司ヒストリーマップ 現代」(時代区分に合わせ時代名、現代が変わっていく)(時代に合わせフォントがゴシック、明朝体、筆文字系と変わっていく。明朝は大正以降、ゴシックは現代)
左に上下のスライダー。スライダーの左に年表がならぶ。上が現代、下が縄文。年表は基本的なことだけ並べる。日中戦争や真珠湾攻撃や門司駅の完成のような本当に基本的な、門司が関わりつつも日本の歴史とも言えるようなことも含む、大きなことだけを表示。年表をマウスオーバーで門司の詳細年表をスライダー右に別窓で表示。詳細年表は別窓だけど縄文から現代までの詳細なことを一つの窓で並べ、位置に応じて一部だけを見せるという感じ。
下の帯では史跡一覧を出す。史跡一覧は左端は縄文、右は最も現代。時代スライダーを動かすと、一覧もその時代に合わせて自動でスクロール。
スライダーは年代を詳細に動かせる。ただし、マップのピンの入れ替えは時代の区切りで入れ替える感じ。
### 地図仕様
ここはインパクトの大部分なので、ビジュアル的に気を使う。以前記述したことを行う。
加えて、threejsで、軽く3D化する。木っぽいものを描画し、波打ち際で波っぽいものを描画する。イメージはパラドゲーのマップ。軽さを確保する程度にほどほどにしつつベストを尽くす。
### 史跡詳細画面
MVPとしての割り切りをするため、詳細に中身を用意したものだけ、ピンに赤い矢印をストロークのアニメーションで向けてアピールする。各時代基本一個。
クリックでダイアログが出て、中身を見れる。
ダイアログは疑似ウィンドウを用意。ウィンドウはピンの画面内の位置に合わせ、隠れない位置に出す。ピンが下の方なら上にだす。ウィンドウの枠にはピンに向けて吹き出しのあれみたいなのをつける。マップを動かしても、吹き出しのあれは追従する。ピンには被らないようにウィンドウを少し動かす。バツボタンを一応用意するが、べつのピンをクリックで別のウィンドウを出したときは前出したウィンドウを削除する。
中身に、最初に列挙したものを並べる。
一番上にARを表示するためのボタン領域。画像の上にARで探検と書いといて、クリックで疑似ARのための3D空間に移動。
その下に、説明。その下にガイドのボタン。
### 特別仕様
以下のピンに特別な演出を追加する。3Dの描写、光の描写、その他諸々をフル活用する。
平安の壇ノ浦。ピンも特別な大きさで用意。ピンをクリックでマップカメラが特定の場所の斜め視点に遷移し、マップの特別な環境3Dを出す。陣地、船、城等も必要に応じて出し、ベストに戦いを演出する。
門司駅の完成も、駅のモデルに煙を出す機関車が入っていったり出ていったりする。
戦争中は港の稼働と、空襲。
いずれも、カメラを特定の画角に特別に動かし、その視点の中で特別な演出を出す。マップをズームズームアウトしたり動かしたら、即座に諸々を仕舞う。ズームアウトは通常マップの最大ズーム時と同様の状態に遷移して、マップ移動はもとの大きさもとの場所まで遷移する。

### AR画面
横長の360度画像を3D空間上に円状に広げ、円中央に固定されたカメラのむきを動かして眺める。マウスドラッグでカメラの向きを変える。
注目すべきところには丸、その丸を先頭として線が伸び、その先に四角い枠を出し文章の説明をつける。説明も3D空間上に浮かぶ。
左上にもどるボタン。
### ガイドボタン
押すと決済疑似シーケンスとして、stripe風の画面に遷移。決済を確定ボタンを押すと、ガイドの電話番号が出てくる。(サービス内で説明不要だが、千円の大部分はガイドにわたるため、電話番号を知られても個人的なガイドはガイド側が断るため頼めないという設定。一時間という時間の縛りも、ガイド側で管理するという設定。払ったお金はシステムでガイド側に払われるため、不正はガイドが了承しない限り成立しないという設定。)
決済完了後はもとの画面に戻れるものの、一時間はそのボタンの名前が「ガイドとつながる」「決済完了済み 電話番号を表示」に変わり、その状態でクリックで電話番号を確認できるという感じ。
